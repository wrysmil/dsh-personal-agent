# prompt-enhance 安装说明

这是 DeepSeek Harness（DSH）插件，包内是完整源码目录，不是 npm 压缩包。

## 在新电脑安装

1. 把 zip 解压到一个会长期保留的位置，例如 `D:\dsh-plugins\`，
   确认得到 `prompt-enhance\` 目录（里面有 package.json、index.js、client.js）。
2. 打开 DeepSeek Harness，进入左侧 **Plugins（插件）**。
3. 点 **Add plugin（添加插件）**，选择解压出来的 `prompt-enhance` 目录本身
   （选文件夹，不要选里面的某个文件）。
4. 安装后在插件列表确认 `Prompt Enhance` 处于启用状态。
   如果界面没变化，刷新页面或重启 DSH。
5. 在会话输入框右侧出现「闪光」按钮，即为安装成功。

## 注意

- 本地目录安装是**直接链接源码目录**，安装后不要移动或删除该目录，否则插件会失效。
- 该插件不依赖任何外部 npm 包，也不需要额外配置密钥。
- 若目标机器已装过同名插件，先移除旧的再安装，避免指向旧路径。

## 功能（1.2.0）

点一下输入框右侧的闪光按钮，把下面这些一起交给当前会话的模型，改写出可直接执行的提示词并回填输入框：

- 输入框里的草稿；
- 草稿里用 `@` 引用的文件/会话（标签与来源）；
- 输入框里已附加的附件（文件名、大小、类型、图片尺寸，不含正文）；
- 本会话最近两轮对话（仅用于消解指代）。

不读磁盘、不读项目规则、不读技能目录。详见 `docs/DETAIL.md`。
